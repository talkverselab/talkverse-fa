# 회화 작성 규칙 — 페르시아어 Claude 초안 (2026-11-07)

공통 원칙 https://talkverse.uk/talkverse/dialogue-rules/ · 일본어앱 §12 흐름 · `docs/DIALOGUE_NOTES.md` · `CHARACTERS.md`. 편 목록 = `data/dialogue_plan_fa.csv`. 이 파일은 편 하나를 쓸 때의 체크리스트다.

## 톤(가장 중요)
- 학습자가 외우고 싶은 한 줄이 편마다 있다. 킥(웃음·놀람)은 코믹하게 편마다 1회. 현실에서 일어날 법한 사고.
- 교과서체·번역투·설명하는 대사·다짐이나 감사로 끝맺기 금지. 끝 줄은 짧은 한 방.
- 구조: 질문 → 대답 + 이유나 농담 → 상대가 받아 되치기. 설명이 아니라 반응으로 정보가 나온다.
- 이란 사람이 실제로 쓰는 짧은 표현(`data/expressions/top_expressions.csv`)을 편마다 2개 이상, 자연스럽게. 타로프(ta'arof) 주고받기는 이란다운 킥 재료.
- 연애 = 썸·플러팅까지, 여성이 먼저 다가가는 편을 더 많이, 심쿵(마음을 들키는 말·말끝 흐리기·여운)을 편마다 한 줄. 클리셰는 일부만.
- 수위 iOS 12+. 이란 무대이므로 술·클럽·공공장소 신체 접촉·정치·종교 풍자·히잡 논쟁 장면은 쓰지 않는다. 남녀 만남은 카페·공원·서점·채팅·친구 모임으로. 해당 턴이 민감하면 `flags`.
- 실존 인물·브랜드·작품·방송 이름 금지(앱 이름은 「앱」, 메신저는 「채팅」). 전부 자체 작문.

## 칸
- `tl` = **표준 글말 철자**, `tl_col` = **테헤란 입말**(채팅에서 실제로 치는 철자, می‌خوام·نمی‌دونم·خوبه·اون·رو·باهات). 둘이 같으면 `tl_col` 도 같은 문장으로 채운다. 입말을 먼저 쓰고 글말로 옮긴다 — 대사의 기준은 입말.
- `rd` = **입말(`tl_col`)을 읽은 한글 독음**(앱 🔊 도 입말을 읽음). 표기는 `docs/DIALOGUE_NOTES.md` §4. 긴 â=어, 짧은 a=아, e=에, o=오, i=이, u=우, خ=ㅋ, ق·غ=ㄱ. 라틴 문자·빈칸 금지. 변수는 그대로 `{name}`.
- `ko` = 한국 사람이 실제로 하는 말(직역 금지), 말투는 페르시아어 쪽과 같게.
- `note` = 핵심 하나 `표현 = 뜻`, 왼쪽은 페르시아어(입말), 오른쪽은 한국어. 에자페·می‌ 등 문법 포인트는 짧게.
- `tags` = `expr:<표현>`(표현 풀에서 쓴 것) · `form:<문법>` · `callback:<편id>`. `new` = 이 턴에 처음 나온 내용어 기본형. 채팅 편은 `"ui":"bubble"`, `"at":"22:41"`, 이모지는 tl 이 아닌 `"stamp"`, 읽씹은 `"read":false`.
- ZWNJ(می‌، نمی‌، ‌ها، ‌ام) 지우지 말 것. 페르시아 글자 ی ک 만(아랍 글자 ي ك 금지). 물음표 ؟ 쉼표 ،.

- `emotion` = 음성용 감정(사용자 지시 2026-11-07, 턴마다 필수): neutral polite stiff cheerful amused teasing excited surprised shout tsukkomi annoyed sad worried flustered shy gentle. neutral 만 쓰지 말 것. 한 턴에서 감정이 바뀌면 `segs` = `[[감정, 입말 본문], …]` 로 나눈다(이어 붙이면 `tl_col`). 편의 `cast` = A 외 인물의 목소리(`data/tts/voices.json`). 음성 계획은 이 칸들에서 `tools/tts/make_plan.py` 가 자동으로 만든다.

## 인물
A = 학습자 `{name}`(국적·이름 고정 금지, `{country}`·`{city}`, 말이 성별로 안 바뀜 — ko 호칭도 중립). B = 주제 고정 인물:
- 사라 سارا(친구·여행): 수다, 도시 안내, 끼어들기.
- 네가르 نگار(연애·문화): 조용한데 한마디가 날카로움, 먼저 마음을 들킴, 미대생.
- 아라시 آرش(생활·연애 일부): 바리스타, 차 이야기를 길게 함, 다정.
- 레자 رضا(친구·일·학업): 장난꾸러기, 축구, 해바라기씨, 몸짓이 큼.
- 이름 없는 조연: 택시 기사(راننده)·가게 주인·아주머니·집주인. 타이밍이 기막힘.

## 양식
- 말투: 낯선 사이·거래·일 = شما + 복수 동사(ko 존댓말), 친구·연인 = تو(ko 반말). 가까워지는 전환 편에서 شما → تو 를 가르친다.
- 턴 수: R1 6~8 · R2 8~12 · R3 12~16. 턴 1~2문장. 단어 수(입말, 띄어쓰기 기준, 경동사 덩어리 = 2): R1 3~8 · R2 4~12 · R3 4~16. 1단어 턴은 반전·끝 펀치라인·채팅 편에만.
- 어휘: 쉬운 말 우선. R1 은 절벽 단어 상위 300위 안 + 편당 장면어 3개까지, R2 는 561위 안, R3 은 1,500위 안 위주(`assets/data/freq/lang_es_top.csv`, 검사기가 비율을 보여 준다). 새 단어 턴당 ≤3(R1)·≤4(R2·R3).
- 반전 = 계획표의 `twist_type`(chaos·slip·reveal·emotion·ignore) 그대로, 본론 후반 턴 번호를 `twist` 에.
- **일상 속 반전(사용자 지시 2026-11-09, 공통 원칙 §9)**: 무대는 학습자가 실제로 겪는 일상(가게·식당·길·집·학교·직장·약속·전화)이고 그 자리의 실제 표현 흐름이 대사의 뼈대. 반전·러브·플러팅은 줄이지 않는다(비율 기준 그대로) — 그 일상 흐름 속에서 터지게 한다. 금지는 일상과 동떨어진 비현실적 설정(억지 우연 「알고 보니 그 사람이 ○○」, 동네·건물 전체 소동, 판타지)뿐. chaos 도 실제 장면 안에서 커지는 꼬임. `goal` 은 그 장소에서 실제로 쓰는 말(주문·값 묻기·길 묻기·약속 잡기 등).

## 파일 — `assets/data/dialogues/<region>/<island>/<id>.json`
```json
{"id":"r1_love_c1","region":"R1","island":"love","kind":"chat","draft":true,
 "purpose":["love"],"domain":["love"],"title":"…","emoji":"💬","scene":"장면 한 줄","where":"장소",
 "speakers":{"A":"{name}","B":"نگار"},"register":"polite|casual|chat|mixed","twist":5,"twist_type":"emotion","flags":[],
 "goal":"학습 목표 한 줄","expressions":["표현 풀에서 쓴 것"],
 "turns":[{"num":1,"speaker":"B","tl":"…","tl_col":"…","rd":"…","ko":"…","note":"… = …","tags":[],"new":[],"emotion":"cheerful"}]}
```
쓴 뒤 `python3 tools/check_dialogues_fa.py <파일…>` 오류 0. 공개 저장소이므로 출처·작품명 금지.

## 말장난·말실수
slip 편의 오해는 **페르시아어에서 실제로 성립해야** 한다(비슷한 소리·한 글자 차이·타로프 오해). 계획표 장면이 페르시아어로 안 되면 twist_type 은 두고 장면을 바꾼다. 한국어로만 웃긴 말장난 금지.
