> 상태(2026-11-02): 지금 앱의 회화는 공통 원칙 이전 초안(5편 × 8턴, 원본 `~/talkverse/_update_kit/content/fa.py`)이다.

## 1. 기본 변이

- **이란 페르시아어(파르시, `fa_IR`)** 하나. 다리어(아프가니스탄)·타지크어는 만들게 되면 별도 파일.
- **표기는 표준 문어 철자, 대화체는 테헤란 구어를 쓴다(제안).** 페르시아어는 문어/구어 차이가 커서(است → ـه, می‌خواهم → می‌خوام) 한 턴 안에서 섞지 않는다.
  지금 초안은 문어 철자 + 일부 구어 발음 독음이 섞여 있다 → 새로 만들 때 구어로 통일하거나, 문어로 통일하고 독음도 문어 발음으로 맞출 것.
- 아랍 문자 · 오른쪽에서 왼쪽(RTL). 화면에서 `tl` 칸은 `TextDirection.rtl` 로 그린다(앱 처리 확인 필요). ZWNJ(‌, می‌ 등)를 지우지 않는다.

## 2. 성별판

- 문법 성이 없고 화자 성별로 동사·어미가 바뀌지 않는다 → **한 판**(성별판 없음).
- 3인칭 او 는 남녀 공용. 한국어 번역에서 그/그녀는 맥락으로.

## 5. 그 밖

- 등장인물(초안): A = 민준(한국인 학습자), B = 사라(이란 현지인), 장소 테헤란. 공통 원칙 §1 의 목적·도메인 태그로 다시 정리한다.
- 경어: 낯선 사이 شما + 복수 동사, 친구 تو. 가까워지는 전환 장면에서 شما → تو 를 가르친다(공통 원칙 §5).
- 템플릿 잔재 정리 대상(공통 원칙 §12): 회화 칸 이름 `es`, `assets/data/dialogues/_meta.json` 의 `lang: "es"`·카스티야 설명, `freq/lang_es_top.csv`(빈 파일).

## 6. 반전·그림 (2026-11-03 사용자 지시, 공통 원칙 §9)

- 편마다 `twist_type` 하나(chaos · slip · reveal · emotion · ignore). **카오스 30% 이상** — 이 앱은 150편 이내라 45편 이상.
- 심쿵 많이: 연애·플러팅 편마다 한 줄, 여성이 먼저 다가가는 편을 더 많이. 새 편은 왕초보·초급(R0·R1) 위주.
- 장면 그림 = A·B 대화 한 쌍당 1컷, 말풍선·글자 없음, 인물 기준 그림(`data/review/art/chars_fa_v1.jpg`, 주인공+조연) 첨부.
