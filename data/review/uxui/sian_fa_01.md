## 1. 콘셉트

한국 학습자가 페르시아어에서 처음 막히는 곳은 문법보다 **글자**다: 오른쪽에서 왼쪽으로 쓰고, 같은 글자가 낱말 안 위치에 따라 모양이 바뀐다. 그리고 회화로 들어가면 **적힌 문장과 테헤란 사람이 실제로 하는 말이 다르다.**
그래서 리더의 장면 컷·스크립트는 그대로 두고, 「글자를 눌러 모양을 보는 칸」과 「글말 ↔ 입말 한 줄 비교」 두 가지만 더한다. 나머지는 한국어와 닮은 점(동사가 끝, 「명사 + 하다」 꼴)을 짧은 표지로 알려 줄 뿐 설명을 늘리지 않는다.

## 2. 제안 칸 ① 글자 모양 시트(리더 안)

- **무엇:** 스크립트의 페르시아어 줄에서 낱말을 탭하면, 그 낱말을 글자 단위로 풀어 각 글자의 4가지 모양(홀로·앞·가운데·끝) 중 **지금 쓰인 모양을 강조**하고, 오른쪽→왼쪽 읽기 화살표 위에 글자마다 한글 소리를 단다.
- **어디:** 리더 오른쪽 칸 캡션 아래에서 올라오는 시트(폰은 아래에서 올라오는 시트). 장면 컷은 가려지지 않게 시트 높이 40% 이하.
- **동작:** 낱말 탭 → 시트 → 글자 칩 탭 → 그 글자의 4모양 카드 + 🔊. 「익힌 글자」에 더해짐(성과 칸).
- **만드는 법(콘텐츠 아님):** 32글자 × 위치 규칙은 유니코드 결합 규칙으로 계산한다(표 하나, 앱 코드). 소리는 `docs/DIALOGUE_NOTES.md` §4 독음 표기표.

```
┌ 리더 오른쪽 칸 ───────────────────────────────┐
│ [장면 컷 — 사라·학습자, 카페]                   │
│ ┌ 캡션 ─────────────────────────────────────┐ │
│ │        سلام! من مینجون هستم.  ◀ 읽는 방향 │ │
│ │ 살롬! 만 민준 하스탐. / 안녕! 나는 민준이야. │ │
│ └───────────────────────────────────────────┘ │
│ ┌ 글자 시트: هستم (하스탐 · ~이다) ───────────┐ │
│ │  ◀─────────────────────────────            │ │
│ │  [م]끝   [ت]가운데  [س]가운데  [ه]앞       │ │
│ │   ㅁ        ㅌ         ㅅ         ㅎ        │ │
│ │  ه : ه(홀로) ﻫ(앞●) ﻬ(가운데) ﻪ(끝)  🔊      │ │
│ └───────────────────────────────────────────┘ │
└───────────────────────────────────────────────┘
```

## 3. 제안 칸 ② 글말 ↔ 입말 한 줄(자막 칩 하나 추가)

- **무엇:** 하단 자막 칩에 「입말」 하나를 더한다. 켜면 스크립트·캡션에서 페르시아어 줄 바로 아래에 테헤란 입말을 작은 보라색 줄로 보여 주고, 글말과 달라진 부분만 밑줄.
- **어디:** 하단 고정 컨트롤 자막 칩 `فارسی · 입말 · 독음 · 한국어`. 입말 데이터가 없는 편은 칩을 숨긴다(지금 초안은 없음 → 회화 작업 뒤 켜짐).
- **동작:** 칩 켜기/끄기, 줄의 🔊 은 입말 쪽을 읽는다(입말이 있을 때).

```
 1  A   ‎سلام! من مینجون هستم. تو چطوری؟          🔊
        ‎سلام! من مینجونم. تو چطوری؟   ← 입말(달라진 곳 밑줄)
        살롬! 만 민준암. 토 체토리?
        안녕! 나는 민준이야. 너는?
```

## 4. 전체 리더(아이패드 가로, 900 이상) — 두 칸을 얹은 모습

```
┌─레일─┬─ 대화 스크립트 ──────────────────┬─ 장면 컷(주인공) ───────────────────┐
│ 홈   │ 1 A  سلام! من مینجون هستم. ●    │ ┌────────────────────────────────┐ │
│ 학습●│      살롬! 만 민준 하스탐.         │ │ [점토풍 컷: 카페, 사라·학습자]  │ │
│ 진행 │      안녕! 나는 민준이야.          │ │   말풍선: سلام! …               │ │
│ 나   │ 2 S  سلام، اسم من سارا است.      │ └────────────────────────────────┘ │
│      │      살롬, 에스메 만 사라 아스트.   │ 캡션: 페르시아어(오른쪽 정렬)         │
│      │ 3 A  …                          │       독음 · 한국어(왼쪽 정렬)        │
│      │                                 │ ┌ 글자 시트(낱말 탭 때만) ────────┐ │
│      │                                 │ │ ◀ م ت س ه  · 4모양 · 🔊          │ │
│      │                                 │ └────────────────────────────────┘ │
├──────┴─────────────────────────────────┴────────────────────────────────────┤
│ ▶ 재생  ━━━●━━━━━━  2/8   속도 1x   자막 [فارسی][입말][독음][한국어]          │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 두 방향이 섞이는 규칙: 페르시아어 줄만 **오른쪽 정렬·오른쪽→왼쪽**, 번호·화자 점·🔊 은 기존 자리(왼쪽 번호, 오른쪽 🔊) 그대로. 독음·한국어는 왼쪽 정렬. 한 카드 안에서 페르시아어 줄이 맨 위.

## 5. 「나」 탭 성과에 더할 것

- 세는 것에 **「익힌 글자 모양 N / 128」**(32글자 × 4모양 중 글자 시트에서 본 것) 한 줄. 막대 하나, 큰 숫자 없음.
- 안 세는 것은 그대로: 앱 오픈·스트릭·포인트·순위.

```
이번 주 한 줄: 「هستم」 같은 글자 모양을 12개 새로 봤어요
익힌 글자 모양  ▓▓▓▓░░░░░░░░  31 / 128
사랑 · 이야기  ▓▓░░░  1/5편
```

## 6. 하지 않는 것

- 홈·회화 홈·그림 카드·프로필 구조는 바꾸지 않는다(시안 02 그대로).
- 문법 설명 화면을 새로 만들지 않는다 — 「동사가 끝」·「명사 + کردن(하다)」는 스크립트 줄의 작은 표지(💡 note)로만.
- 입말 데이터·새 회화는 회화 작업이 풀린 뒤(사용자 지시 전에는 만들지 않음).
