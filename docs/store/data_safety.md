# 데이터 안전 / 앱 개인정보 보호 답안 (2026-11-02 — 로그인·인앱 구입 포함)

> 한자 앱 `docs/store/data_safety.md` 를 페르시아어유니버스에 맞춘 것.

근거(앱 사실): Talkverse 계정 로그인은 **선택**(구글·네이버·카카오·Apple, 이메일(데모); 서버 auth.talkverse.uk = Cloudflare). 로그인하면 이메일·이름(제공자가 주는 범위)·계정 ID·세션 토큰을 서버에 저장. **인앱 구입** 1개(비소모성 평생 이용권) — 결제는 App Store/Google Play, 앱·서버는 영수증(거래 번호·상품 ID)만 확인. 학습 기록·설정은 기기 안(SQLite·shared_preferences)에만. 광고·분석·크래시 SDK 없음. 추적 없음.
권한: INTERNET, RECORD_AUDIO(말하기 연습, 녹음 저장·전송 안 함), REQUEST_INSTALL_PACKAGES(⚠ GitHub 판 앱 안 업데이트용 — **Play 스토어판에서는 빼야 한다**).

## App Store — 앱 개인정보 보호
| 질문 | 답 |
|---|---|
| 데이터를 수집하나요? | **예** |
| 연락처 정보 → 이메일 주소 | 수집 · 앱 기능(계정 로그인·구매 복원) · 사용자와 연결됨 · 추적 아님 |
| 연락처 정보 → 이름 | 수집(로그인 제공자가 넘기는 경우만) · 앱 기능 · 사용자와 연결됨 · 추적 아님 |
| 식별자 → 사용자 ID | 수집(Talkverse 계정 ID) · 앱 기능 · 사용자와 연결됨 · 추적 아님 |
| 구매 → 구매 내역 | 수집(이용권 복원·기기 간 공유) · 앱 기능 · 사용자와 연결됨 · 추적 아님 |
| 오디오 데이터 | 수집 안 함(음성 인식은 기기 시스템 기능, 앱이 저장·전송하지 않음) |
| 그 밖의 항목 | 수집 안 함 |
| 추적(ATT) | 아니요 |
| 개인정보처리방침 URL | 미정 — talkverse.uk 세션에 페르시아어 앱 방침 페이지 요청 |

## Google Play — 데이터 보안
| 질문 | 답 |
|---|---|
| 수집·공유 | 수집 예 / 공유 없음 |
| 수집 항목 | 이메일 주소·이름(선택, 계정 관리) · 사용자 ID(계정 관리) · 구매 내역(앱 기능) |
| 필수 여부 | 모두 선택(로그인·구매를 해야만 수집) |
| 전송 중 암호화 | 예(HTTPS) |
| 삭제 요청 | 예 — 앱 안 "프로필·설정 → 계정 → 계정 삭제" + https://talkverse.uk/account/delete |
| 앱 액세스 권한 | 모든 기능이 로그인 없이 사용 가능 — 데모 계정 review@talkverse.uk 를 안내에 적음 |
| 광고 · 광고 ID | 아니요 |
| 디지털 구매 | 예 — 인앱 구입 |
